Why it animates on GitHub

It is a SMIL-animated SVG referenced as an <img>. GitHub serves it as a file, so the motion plays — no JavaScript needed.

Reads on both canvases

The art carries its own near-black backdrop, so it looks identical on GitHub light or dark. Toggle above to confirm.

Retheming

All colors are flat hex constants — edit the palette block at the top of gen_header.py (or search #ff2f3f in the SVG) and regenerate.
